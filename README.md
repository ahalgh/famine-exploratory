# famine-exploratory

Exploratory analysis of food-security early-warning data (FEWS NET IPC, SMART soil-moisture trigger, prices, conflict) for Guatemala, Kenya, Malawi, Nigeria, Somalia and Uganda.

`data/` is git-ignored. Place the provided `inputs/`, `outputs/` and `regions/` folders under `data/`.

## Python

```bash
pip install -r requirements.txt
```

- `famine/loaders.py`: typed loaders for every dataset (see [FEATURES.md](FEATURES.md) for the column dictionary)
- `famine/smart.py`: SMART re-implementation (paper Eq. 1–3, plus the variant that reproduces the shipped outputs)
- `famine/backtest.py`, `scripts/smart_false_positives.py`: false-positive backtest against observed FEWS transitions
- `notebooks/eda.ipynb`: EDA (generated by `scripts/build_eda_notebook.py`)

## Coverage map (Svelte + MapLibre)

1. Download GeoNames gazetteers for GT, KE, MW, NG, SO, UG from https://download.geonames.org/export/dump/ into `data/external/geonames/` (unzip to `<CC>.txt`).
2. Build the map data:

   ```bash
   python scripts/geocode_markets.py   # -> reports/market_locations.csv
   python scripts/export_map_data.py   # -> web/public/data/ (git-ignored)
   ```

3. Run the app:

   ```bash
   cd web && npm install && npm run dev
   ```

The light-mode base map is OpenFreeMap (no API key). Without network access, or in dark mode, the map shows only the boundaries.

Not yet mapped: FEWS livelihood zones (needs the FEWS NET zone shapefiles) and soil-moisture regions (no boundaries in the data).
